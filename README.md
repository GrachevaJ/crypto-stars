# Cryptostar — сервис P2P-обмена криптовалюты

Одностраничное веб-приложение для поиска контрагентов и обмена криптовалюты KEKS на рубли онлайн или за наличный расчёт при встрече.

---

## 🛠 Технологический стек

* **Core:** JavaScript (ES6+), HTML5, CSS3
* **API & Data:** REST API (Fetch API, JSON, `multipart/form-data`)
* **Библиотеки:** Leaflet, PristineJS
* **Качество кода:** ESLint (стандарты HTML Academy)

---

## ✨ Реализованный функционал

* **Работа с данными и сквозная фильтрация:** Асинхронная загрузка данных пользователя и списка контрагентов. Фильтрация предложений по направлению сделки (покупка/продажа) и статусу верификации с сохранением состояния при переключении режимов просмотра.
* **Интерактивная карта (Leaflet):** Визуализация точек обмена за наличный расчёт с кастомными маркерами для проверенных продавцов и интерактивными балунами.
* **Модальное окно обмена и валидация (PristineJS):** Реализован двусторонний пересчёт валют по курсу контрагента в реальном времени, функция «Обменять всё» с учётом балансов обеих сторон и строгая клиентская валидация минимальных и максимальных лимитов сделки.
* **Отказоустойчивость:** Обработка сетевых ошибок при загрузке данных и отправке формы на сервер.
